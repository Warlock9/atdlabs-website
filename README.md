# ATD Labs website

The company website for [www.atdlabs.in](https://www.atdlabs.in), served by GitHub Pages.

- `index.html`: the whole site, one self-contained file. Light, product-led layout focused on Cafe QR (QR table ordering). The contact form sends enquiries through Web3Forms.
- `CNAME`: tells GitHub Pages to serve this site on `www.atdlabs.in`.
