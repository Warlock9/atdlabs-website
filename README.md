# ATD Labs website

The company website for [www.atdlabs.in](https://www.atdlabs.in), served by GitHub Pages.

- `index.html`: the whole site, one self-contained file. Set your WhatsApp number in the `WHATSAPP` line near the bottom and in the Contact section.
- `CNAME`: tells GitHub Pages to serve this site on `www.atdlabs.in`.
